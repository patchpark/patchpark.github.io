# InputBox

입력 버튼에 대하여 오른쪽 마우스 클릭 -> 매크로 지정 -> InputBox를 선택해 준 후 구현한다.

Application.InputBox(프롬프트, 제목, 예시 값,,,,타입)으로 구성되어있으며 특별히 8이 범위 타입이다.

![vba22](https://github.com/user-attachments/assets/42fd463f-9e52-49da-b310-cbbbfd861901)

```vb
Sub InputBox()

    Dim num As String
    Dim selected As String
    Dim rng As Range
    
    num = Application.Caller
    
    If num = "버튼1" Then
        selected = Application.InputBox("성명을 입력하세요.", "성명", "홍길동")
        If selected = "" Then
            MsgBox "입력한 값이 없습니다."
        ElseIf selected = "False" Then
            MsgBox "취소하셨습니다."
        Else
            Range("C6") = selected
        End If
    ElseIf num = "버튼2" Then
        On Error Resume Next
        
        Set rng = Application.InputBox("성별을 선택하세요.", "성별", "성별선택", , , , , 8)
        If rng Is Nothing Then
            MsgBox "선택한 성별이 없습니다"
        Else
            Range("C8") = rng
        End If
        
        On Error GoTo 0
        
    ElseIf num = "버튼3" Then
        selected = Application.InputBox("나이를 입력하세요.", "나이", "나이입력")
        If selected = "" Then
            MsgBox "입력한 값이 없습니다."
        ElseIf selected = "False" Then
            MsgBox "취소하셨습니다."
        Else
            Range("C10") = selected
        End If
    End If
    

End Sub
```
